In Tech News, a closed-loop detection-engineering agent pipeline was demonstrated by the NVIDIA-CrowdStrike team in a purple-team exercise that deploys a red-team agent to execute attacks from a preselected scenario family, records EDR telemetry and ground-truth traces, and then passes them to a blue-team agent to generate candidate detection rules validated against common LLM failure modes and tested for generalization on new attacks from the same family. The work supports training small specialized models for bounded cybersecurity tasks such as detection engineering, distinct from offensive capabilities like vulnerability localization shown in Cisco Antares. It makes sense - if you have a general purpose AI it will naturally be a little worse and get confused by tasks, verses custom tooling designed for each purpose while the main agent is best at digesting feedback and orchestration.
